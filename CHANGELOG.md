# Changelog

Все значимые изменения проекта документируются в этом файле.

## [Unreleased]

### Добавлено
- Режим `single` — расписание на один день.
- Режим `week` — расписание на неделю.
- В режиме `week` расписание на сегодня и на следующий день (минуя выходные).
- В режиме `week` добавлены даты для расписаний.
- Фоновое обновление локальных файлов расписания.

### Изменено
- Удален QR код для входа в админку.
- Поменяны настройки приложения, теперь статику нельзя изменить.

### Исправлено
- Исправлено отображение правильной версии приложения.

## [0.1.3] — 2026-09-25
