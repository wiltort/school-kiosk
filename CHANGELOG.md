# Changelog

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.3.0] — 2026-10-13

### Добавлено
- Учетная запись администратора
- Добавление, удаление, редактирование профиля
- Напоминание при входе на дефолтный профиль
- Блокирование входа в дефолтный профиль при наличии созданных
- Токены авторизации хранятся в БД и удаляются при истечении TTL

### Изменено
- Сброс миграций (в предыдущем наборе были ошибки). Установка без старой базы!
Старые данные переносите вручную. Дальнейшие обновления не требуют удаления БД.

### Исправлено
- Хуки клавиатуры не срабатывали
- Вход в админку в десктопе

## [0.2.0] — 2026-10-02

### Добавлено
- Режим `single` — расписание на один день.
- Режим `week` — расписание на неделю.
- В режиме `week` расписание на сегодня и на следующий день (минуя выходные).
- В режиме `week` добавлены даты для расписаний.
- Фоновое обновление локальных файлов расписания.

### Изменено
- Удален QR код для входа в админку.
- Поменяны настройки приложения, теперь статику нельзя изменить.

### Исправлено
- Исправлено отображение правильной версии приложения.

## [0.1.3] — 2026-09-25

### Добавлено
- Уникальное ограничение на `ScheduleImage.image`.
- Очистка файлов расписания.
- Логирование бэкенда в файл.
- Интеграционные smoke-тесты для релизов.

### Изменено
- Рефакторинг админ-панели на модульные компоненты.
- Сохранение состояния логина в админке.

## [0.1.0] — 2026-06-16

### Добавлено
- Первый релиз.
- Информационный киоск для школ.
