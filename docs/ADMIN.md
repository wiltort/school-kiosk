# Админ-панель School Kiosk

Админ-панель позволяет войти в настройки киоска по логину и паролю, изменить
папку хранения изображений расписания и включить автозапуск программы при входе
в систему. Настройки хранятся **без БД** — в файле `settings.json` в каталоге
данных приложения (`<data_dir>/settings.json`), владелец настроек — бэкенд.

---

## 1. Как попасть в админку

| Среда | Способ |
|---|---|
| **Браузер по локальной сети** | На главном экране нажмите шестерёнку ⚙️ в правом верхнем углу |
| **Десктопный киоск (Tauri)** | Нажмите сочетание **Ctrl+Shift+A** (иконка в браузере не показывается) |

> Открыть киоск из браузера: адрес вида `http://<IP-киоска>:8765/` (см. панель
> «подключиться по локальной сети» на главном экране).

В обоих случаях откроется экран **«Вход в админку»**.

## 2. Вход

Логин и пароль по умолчанию:

```
Логин:   admin
Пароль:  admin
```

Значения по умолчанию задаются в конфиге бэкенда
([`backend/src/core/config.py`](../backend/src/core/config.py)) переменными
`BACKEND_DEFAULT_ADMIN_LOGIN` и `BACKEND_DEFAULT_ADMIN_PASSWORD`. Их можно
переопределить через окружение при запуске бэкенда.

> **Рекомендация.** Перед использованием в реальной школе смените пароль
> (задайте `BACKEND_DEFAULT_ADMIN_PASSWORD`), т.к. значение по умолчанию
> общеизвестно.

После успешного входа бэкенд выдаёт Bearer-токен; сессия живёт в памяти
бэкенда и сбрасывается при его перезапуске. Кнопка «Выйти» завершает сессию.

## 3. Настройки

### 3.1. Папка для изображений расписания

Поле пути на диске киоска (например `D:\KioskStatic`). Пустое поле —
используется папка по умолчанию (`<data_dir>/uploads`).

- Значение сохраняется сразу после нажатия «Сохранить».
- **Применяется при перезапуске киоска/бэкенда** — монтаж `/uploads` происходит
  на старте. После сохранения перезапустите приложение, чтобы папка вступила
  в силу.
- При смене папки **старые** изображения не переносятся автоматически: в БД
  хранятся относительные пути к файлам, поэтому новые изображения будут
  попадать в новую папку, а прежние останутся на старом месте.

> Совместимость с установщиком: если при установке был указан параметр
> `/STATICDIR=...`, этот путь подхватывается бэкендом при первом запуске как
> «seed» и становится текущим значением настройки.

### 3.2. Автозапуск при входе в систему

Переключатель «Автозапуск программы при входе в систему».

- Работает **только на Windows**: бэкенд создаёт/удаляет **ярлык `.lnk`** для
  `kiosk.exe` в папке автозагрузки пользователя:
  ```
  %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\School Kiosk.lnk
  ```
- Ярлык создаётся штатным системным инструментом (PowerShell / WScript.Shell).
  Использование папки Startup (вместо прямой записи в ключ реестра `Run`)
  не вызывает срабатывание антивируса, который блокирует изменение
  `HKCU\...\CurrentVersion\Run` из процесса Python.
- Применяется **сразу** после сохранения (перезапуск не нужен).
- На других ОС переключатель недоступен (отключён), т.к. автозагрузка не
  поддерживается.

## 4. Где хранятся настройки

Файл `settings.json` в каталоге данных приложения:

| Поле | Тип | Описание |
|---|---|---|
| `static_dir` | строка \| null | Каталог изображений; `null` — значение по умолчанию |
| `autostart` | bool | Включена ли автозагрузка при входе в систему |

Пример:

```json
{
  "static_dir": "D:\\KioskStatic",
  "autostart": true
}
```

Каталог данных:
- **dev-режим** — `backend/data/`;
- **продакшен (Tauri)** — `%LOCALAPPDATA%\com.schoolkiosk.app\`.

Файл можно редактировать вручную, но основной способ — через админ-панель.

## 5. HTTP API (для разработчиков)

Все эндпоинты под префиксом `/api/v1/admin`:

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/v1/admin/login` | Вход: `{"login", "password"}` → `{"token"}` |
| `POST` | `/api/v1/admin/logout` | Выход (требует Bearer-токен) |
| `GET` | `/api/v1/admin/settings` | Текущие настройки (требует токен) |
| `PUT` | `/api/v1/admin/settings` | Сохранить настройки (требует токен) |

Заголовок авторизации: `Authorization: Bearer <token>`.

Пример сохранения настройки:

```bash
curl -X POST http://127.0.0.1:8765/api/v1/admin/login \
  -H "Content-Type: application/json" \
  -d '{"login":"admin","password":"admin"}'
# → {"token":"..."}

curl -X PUT http://127.0.0.1:8765/api/v1/admin/settings \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"static_dir":"D:\\KioskStatic","autostart":true}'
```

Ответ `GET /admin/settings` содержит также `autostart_supported` — поддерживает
ли платформа автозагрузку.

## 6. Проверка после изменения папки

1. Сохраните папку в админке.
2. Полностью перезапустите киоск (или бэкенд).
3. Убедитесь, что новые изображения расписания сохраняются в выбранную папку.
