# План разработки

## Профиль администратора
- смена логина и пароля
- редактирование профиля
- удаление профиля
- добавление профиля

## Use-cases:
### Первый вход в админку по дефолтному логину и паролю
- Пользователь вводит логин и пароль admin/admin
- На главном экране появляется меню администратора, иконка админ режима имеет галочку.
- Появляется окно с напоминанием о необходимости сменить логин и пароль
по умолчанию, для этого надо создать профиль администратора. В этом окне есть кнопка
создать профиль администратора и кнопка отменить.
- При нажатии на кнопку создать появляется форма создания профиля с полями:
   - Логин
   - Пароль
   - Повтор пароля
   - email (необязательно) (с подтверждением)
   - ФИО (необязательно)
И кнопками отменить и создать.
- После создания профиля зайти по дефолтному логину и паролю уже невозможно.
- При создании - емайл уведомление
- Появилась иконка профиля - изображение человечка

### Смена логина и пароля.
- Пользователь входит под своими логином и паролем (не дефолтными)
- На главном окне появляется меню администратора, иконка админ режима имеет галочку, есть иконка профиля.
- Пользователь нажимает на иконку профиля и выбирает пункт меню смены логина и пароля.
- На странице смены пароля есть поля:
  - Пароль
  - Повтор пароля
- После нажатия на кнопку сменить пароль, происходит смена пароля.
- На электронную почту приходит письмо с новыми логином и паролем

### Редактирование профиля
- Пользователь входит под своими логином и паролем (не дефолтными)
- На главном окне появляется меню администратора, иконка админ режима имеет галочку, есть иконка профиля.
- Пользователь нажимает на иконку профиля и выбирает пункт меню редактирование профиля.
- На странице редактирования профиля есть поля:
  - Логин
  - ФИО
  - email (c подтверждением)
- После нажатия на кнопку сохранить, происходит сохранение профиля.

### Подтверждение почты
- На странице создания или редактирования профиля при вводе email появляется еще одно поле - код подтверждения.
- Генерируется секретный ключ, сохраняется пара email-код подтверждения.
- На указанную почту отправляется емейл с кодом подтверждения.
- При вводе кода подтверждения происходит подтверждение почты.
- Если код не приходит, можно повторить отправку через 2 минуты или отменить.
