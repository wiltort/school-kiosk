# Иконки приложения

Tauri требует набор иконок (`.png`, `.ico`, `.icns`), на которые ссылается
`tauri.conf.json` → `bundle.icon`.

## Как сгенерировать

Положите в папку `src-tauri/icons/` исходный файл `app-icon.png`
(минимум 1024x1024, желательно с прозрачным фоном) и выполните:

```bash
cd src-tauri
cargo tauri icon ./icons/app-icon.png
```

Команда автоматически создаст все нужные размеры:
`32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`, `icon.ico`
и другие.

Для dev-сборки (`cargo tauri dev`) иконки не обязательны, но нужны для
`cargo tauri build` (создание установщика).

> Если исходного `app-icon.png` нет — можно сгенерировать заглушки той же
> командой из любого PNG-файла, например из `media/logo.svg` (предварительно
> конвертировав в PNG).
